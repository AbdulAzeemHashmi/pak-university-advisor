# 🎓 Pak University Advisor

A bilingual (English/Urdu) web application helping Pakistani students find the best university based on budget, location, and degree preferences. Features AI-powered recommendations and need-based scholarship data.

## 🚀 Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Database:** Xata.io (15 GB free tier)
- **Auth:** Auth.js (NextAuth.js) v5
- **UI:** Tailwind CSS + shadcn/ui
- **i18n:** next-intl (English/Urdu, RTL support)
- **AI:** OpenRouter (free models)
- **Email:** Resend (3,000 free emails/month)
- **Deployment:** Vercel (free hobby plan)

npm install
